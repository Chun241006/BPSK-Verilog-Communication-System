## How to reproduce

In Windows PowerShell from the repository root:

```powershell
New-Item -ItemType Directory -Force simulation/results | Out-Null
vlog -sv +incdir+. rtl/bpsk_modulator.v rtl/channel.v rtl/bpsk_demodulator.v rtl/ber_counter.v rtl/bpsk_top.v tb/tb_bpsk_system.v
vsim -c tb_bpsk_system -do "run -all; quit -f"
```

Expected summary:

```text

# Errors: 0, Warnings: 0
```

## Verification limits

- These scenarios are not exhaustive verification of every possible input timing or multi-symbol error pattern.
- The channel models deterministic sign inversion, not additive white Gaussian noise.
- The shown integrated cases inject at most one selected error symbol in a case; multiple-error functionality was exercised only at the BER unit-test level during earlier testing.
- The recorded pass applies to the tested RTL and reference memories; regenerate and rerun if either changes.

## Additional member evidence

- Member 1: modulator bit 0 and bit 1 waveform/CSV sample checks passed (8 valid samples each).
- Member 2: Both standalone demodulator tests passed. Scenario 0 recovered 16 bits with 0 errors (BER = 0%). Scenario 1 recovered 16 bits with one intentionally inverted symbol at index 3 (BER = 6.25%). Both tests reported zero RTL mismatches.
